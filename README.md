## 特性

**共同特性**

- 🔒 **完全本地化**：歌单、收藏、播放历史、设置、可选的登录凭据全部存放在用户设备本地，采用原子写入 + 自动备份，不上传任何数据
- 🎵 **音频流中继播放**：本地服务从第三方平台公开接口获取音频流后向本地播放器中继，支持进度拖动（Range 请求）
- 📋 **歌单导入**：粘贴第三方平台歌单分享链接即可导入元数据；采用「懒匹配」机制（导入时只读元数据，首次播放时才检索音源），避免对平台造成批量请求压力
- 🔐 **可选登录态**：通过第三方平台官方二维码页面授权，会话凭据仅存本地，可随时清除；登录用于获取更高音质
- 🧹 **去品牌化设计**：发布版本中第三方平台一律以「某弹幕网站」「某音乐平台」指称，示例域名采用 RFC 2606 保留域名

**PC 端（Windows）**

- 单实例运行，启动即屏蔽重复启动
- 应用窗口模式（Edge 应用模式 / WebView 备选），注册 AUMID 以显示独立任务栏图标
- 本地 HTTP 服务仅监听 `127.0.0.1`，不对局域网与公网开放
- 全局热键、均衡器、下载管理（用户主动触发，保存位置可配置）
- 仅依赖 Python 标准库，PyInstaller 打包

**手机端（Android）**

- 单文件 WebView 应用，前端资源全部内置于安装包
- NativeBridge 与系统能力交互（通知、外部存储、剪贴板）
- 适配圆角图标（squircle）渲染

## 快速开始

### PC 端

要求 Python 3.11+（开发与测试基于 3.13）：

```bash
cd pc
python app.py
```

首次启动会在本机 8765 端口（仅回环地址）启动本地服务并打开应用窗口。

打包为 Windows 可执行程序：

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=web/icon.ico --name 椰子音乐 app.py
```

### 手机端

方式一：直接安装 `mobile/椰子音乐4.apk`（需允许安装未知来源应用）。

方式二：自行构建 —— `mobile/index.html` 是完整的前端源码，可放入任意 WebView 容器运行；仓库中的 APK 即由其构建而来。

## 技术要点

- **搜索匹配**：以第三方平台的元数据（歌名/歌手）为歌曲身份，某弹幕网站的搜索结果仅作音源候选，匹配算法综合标题归一化、时长、上传者前缀等因素打分
- **音频流代理**：本地 HTTP 服务代理 Range 请求，实现拖动进度；仅取音频流（DASH audio），不触碰视频流
- **歌单懒匹配**：导入的歌单中每首歌仅在首次播放时匹配一次音源，避免重复搜索触发平台风控
- **本地数据库**：JSON 原子写入（临时文件 + 改名），每次保存前自动生成 `.bak` 备份
